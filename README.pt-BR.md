# awesome-claude-skills-es-pt

**As melhores skills de agentes de IA, no seu idioma.**

Um diretório curado de skills para Claude Code, Codex e outros agentes de IA —
explicado em português e espanhol, para que a comunidade lusófona e hispanohablante
não precise traduzir nada.

🇧🇷 Este README está em português · 🇪🇸 [Leer en español](README.md)

---

## O que é uma "skill"?

Uma skill é um pacote de instruções e ferramentas que ensina um agente de IA
a fazer bem uma tarefa específica: revisar código, escrever documentos, analisar dados,
auditar segurança… Em vez de explicar tudo do zero toda vez, você instala a skill
e o agente já sabe como trabalhar.

## Critérios de inclusão

Para entrar neste diretório, cada projeto precisa cumprir tudo isto:

1. **Existe de verdade.** Cada link foi verificado na API do GitHub
   (`https://api.github.com/repos/<owner>/<repo>`) com resposta 200.
   O que não passou na verificação, não entrou.
2. **Tem conteúdo real.** Nada de repositórios vazios nem de "em breve".
3. **Está vivo ou tem peso.** Atividade no último ano, ou um número de stars
   que mostra uso real.
4. **É útil para alguém.** Cada entrada diz para quem ela serve.

> ⭐ Os números de stars foram verificados em **6 de outubro de 2026** via GitHub API.
> Podem ter mudado desde então.

## Comece aqui

Se é sua primeira vez com skills, instale nesta ordem:

1. **[anthropics/skills](https://github.com/anthropics/skills)** — o repositório oficial. Entenda o formato.
2. **[obra/superpowers](https://github.com/obra/superpowers)** — a metodologia. Aprenda a trabalhar com agentes.
3. **[CHEATSHEET.md](CHEATSHEET.md)** — escolha 2 ou 3 skills da sua área e teste hoje.

## Como contribuir

Conhece uma skill que deveria estar aqui? Abra uma issue com:

- o link do repositório,
- uma frase em espanhol e outra em português explicando para que ela serve.

Só entram repositórios que passem nos critérios acima.
