# awesome-claude-skills-es-pt

**Las mejores skills de agentes de IA, en tu idioma.**

Un directorio curado de skills para Claude Code, Codex y otros agentes de IA —
explicado en español y portugués, para que la comunidad hispanohablante y lusófona
no tenga que traducir nada.

🇪🇸 Este README está en español · 🇧🇷 [Leia em português](README.pt-BR.md)

---

## ¿Qué es una "skill"?

Una skill es un paquete de instrucciones y herramientas que le enseña a un agente de IA
a hacer bien una tarea concreta: revisar código, escribir documentos, analizar datos,
auditar seguridad… En vez de explicarle todo desde cero cada vez, instalas la skill
y el agente ya sabe cómo trabajar.

## Criterios de inclusión

Para entrar en este directorio, cada proyecto debe cumplir todo esto:

1. **Existe de verdad.** Cada enlace se verificó contra la API de GitHub
   (`https://api.github.com/repos/<owner>/<repo>`) con respuesta 200.
   Lo que no pasó la verificación, no entró.
2. **Tiene contenido real.** Nada de repos vacíos ni de "próximamente".
3. **Está vivo o pesa.** Actividad en el último año, o un número de stars
   que demuestra uso real.
4. **Es útil para alguien.** Cada entrada dice para quién sirve.

> ⭐ Los números de stars se verificaron el **6 de octubre de 2026** vía GitHub API.
> Pueden haber cambiado desde entonces.

## Empieza aquí

Si es tu primera vez con skills, instala en este orden:

1. **[anthropics/skills](https://github.com/anthropics/skills)** — el repositorio oficial. Entiende el formato.
2. **[obra/superpowers](https://github.com/obra/superpowers)** — la metodología. Aprende a trabajar con agentes.
3. **[CHEATSHEET.md](CHEATSHEET.md)** — elige 2 o 3 skills de tu área y pruébalas hoy.

## Cómo contribuir

¿Conoces una skill que debería estar aquí? Abre un issue con:

- el enlace al repo,
- una frase en español y otra en portugués explicando para qué sirve.

Solo se aceptan repos que pasen los criterios de arriba.
